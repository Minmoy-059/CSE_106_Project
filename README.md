# Discrete Mathematics Project (CSE 106)

This project is created for my CSE 106 course. It uses C programming and Adjacency Matrix representation to analyze directed graphs, verify the Handshaking Lemma, and check execution time for different graph sizes.

## What it does
- Generates directed graphs using adjacency matrices (size 1000x1000 up to 5000x5000).
- Calculates in-degrees and out-degrees to verify if total in-degrees equal total out-degrees.
- Measures runtime in milliseconds for N = 1000, 2000, 3000, 4000, and 5000.

## Tech Stack
- Language: C
- Concepts: Graph Theory, Adjacency Matrix, Handshaking Lemma
